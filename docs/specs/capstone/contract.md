# Контракт: Checkout

Итоговая функция: оформление заказа. Полный комплект спецификаций.

## Scope

Оформление заказа: форма адреса, выбор оплаты, отправка через `src/api/checkout.js`, экран подтверждения, очистка корзины.

## Out-of-scope

- Реальная оплата, интеграция с платёжной системой.
- Email-уведомления, SMS-подтверждение.
- Сохранение черновика формы.
- Профиль пользователя, история заказов.

## Acceptance criteria

1. Форма с обязательными полями: имя, телефон, город, адрес.
2. Выбор оплаты: картой, наличными.
3. Итоговая сумма: подытог, скидка по промокоду, доставка, итого.
4. Успешный заказ: показывается номер заказа, корзина очищается через `CartContext.clearCart()`.
5. Ошибка API: сообщение + кнопка повторной отправки.
6. Двойная отправка невозможна: кнопка блокируется на время `submitting`.

## Quality gates (секция контракта)

Допуск к слиянию:

- [x] `npm test` проходит. Покрыто 6+ тестов: валидация формы, успешный submit, ошибка API, повторная отправка.
- [x] `npm run lint` без ошибок.
- [x] `npm run build` без ошибок.
- [x] Форма валидирует обязательные поля до submit.
- [x] Успешный заказ очищает корзину.
- [x] Ошибка API показывает кнопку повтора.
- [x] Интеграционный тест `CheckoutPage.test.jsx` покрывает путь оформления: заполнить форму, отправить, увидеть номер заказа, очистка корзины. E2E-сценарий оформления в `tests/e2e/` пока не заведён (см. риск в `risk-register.md`).

## Rollback (секция контракта)

### Уровень 1. Скрыть оформление заказа

**Когда применять:** API заказов недоступен или возвращает ошибки >50% запросов.

**Как применять:**

1. Через флаг функции скрыть кнопку «Оформить заказ» в корзине.
2. Показать сообщение «Оформление заказов временно недоступно».
3. Восстановить кнопку после стабилизации API.

**Время:** 1-2 минуты через переключение флага в продакшене.

### Уровень 2. Возврат предыдущего релиза

**Когда применять:** баг в нашем коде ломает существующие сценарии (корзина не открывается).

**Как применять:** откатить PR, повторно развернуть предыдущую версию. 10-15 минут.

### Триггеры отката

- Доля ошибок API заказов выше 30% за последние 10 минут.
- Дублирование заказов (двойная отправка по одному пользователю).
- Недоступность страницы оформления.
