# Архитектурные решения: Checkout

## 1. Отдельная страница vs модальное окно
**Варианты:** Checkout как модалка поверх корзины; отдельный route.
**Решение:** Отдельный route /checkout. Модалка усложняет навигацию (back button, URL state). Отдельная страница проще для пользователя и разработчика.

## 2. Управление состоянием формы
**Варианты:** React Hook Form; Formik; локальный useState.
**Решение:** Локальный useState. Форма простая (4 поля). Библиотека добавит зависимость без пропорциональной пользы.

## 3. Обработка ошибок
**Варианты:** Inline ошибки в форме; toast уведомления; отдельный error state.
**Решение:** Inline валидация + error state после submit. Inline для валидации полей. Error state для API-ошибок с кнопкой повторной отправки.
**Связь с рисками:** закрывает риск «Невалидные данные формы» (client-side валидация до submit) и часть риска «API недоступен» (error state с повтором).

## 4. Предотвращение двойной отправки
**Варианты:** блокировка кнопки на время `submitting`; debounce на обработчик; идемпотентный ключ заказа на сервере.
**Решение:** Блокировка кнопки через `disabled={isSubmitting}` плюс текст «Оформляем...». Debounce не спасает от медленного ответа сервера, идемпотентный ключ требует поддержки на бэкенде, которого у проекта нет. Блокировка на клиенте закрывает сценарий целиком.
**Связь с рисками:** основная мера против риска «Двойная отправка заказа» (H-последствия): пока идёт запрос, повторное нажатие невозможно.

## 5. Таймаут запроса на оформление
**Варианты:** без таймаута (ждать ответ сколько угодно); `AbortSignal.timeout`; ручной `AbortController` с `setTimeout`.
**Решение:** `AbortSignal.timeout(10000)` в `submitOrder`. Десять секунд, а не пять как у каталога: оформление пользователь ждёт терпеливее, чем загрузку списка, а обрыв на полпути дороже потерянной секунды. Ручной AbortController даёт тот же результат многословнее.
**Связь с рисками:** снижает риск «API недоступен при оформлении» (H-последствия): по истечении таймаута пользователь получает сообщение и кнопку повтора, а не бесконечное ожидание.
