# Реестр рисков: Checkout

## Технические риски

| Риск | Вероятность | Последствия | Снижение |
|---|---|---|---|
| API недоступен при оформлении | M | H - пользователь не может оформить | Сообщение об ошибке + повтор, таймаут `AbortSignal.timeout(10000)` |
| Двойная отправка заказа | M | H - дублирование заказа | Блокировка кнопки при submitting |
| Невалидные данные формы | H | L - ошибки валидации | Client-side валидация до submit |
| Потеря корзины при перезагрузке | L | M - пользователь теряет товары | Cart в localStorage (будущее) |
| Итоговая сумма неверна на пограничных значениях (пустая корзина, скидка больше подытога) | L | M - пользователь видит некорректное «итого» | Тесты на пограничные суммы, итог не опускается ниже нуля |

## Процессные риски

| Риск | Вероятность | Последствия | Снижение |
|---|---|---|---|
| Спецификация расходится с реализацией при доработках | M | M - следующий разработчик доверяет неактуальному контракту | Обновлять spec-pack тем же PR, ревью сверяет контракт с кодом |
| E2E-путь оформления не прогоняется в CI | L | H - регрессия на критичном для выручки пути незаметна до продакшена | E2E в quality gate, прогон перед слиянием |
