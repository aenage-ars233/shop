## Замечание 2: Добавить маску телефона
- Файл: src/features/checkout/OrderForm.jsx

- Суть: маска ввода для формата +7 (XXX) XXX-XX-XX

## Замечание 4: Добавить индикатор загрузки при отправке

## Замечание 5: Использовать ErrorBoundary вместо try/catch
- Файл: src/features/checkout/CheckoutPage.jsx
- Категория: архитектура

- Решение: адаптировать
- Обоснование: ErrorBoundary полезен для ошибок отрисовки, но API-ошибки обрабатываем через состояние. Оставили try/catch для API, добавили примечание о возможном ErrorBoundary на уровне App.
