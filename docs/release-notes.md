# Release Notes 0.1.0

Учебный релиз магазина после итоговой доработки: добавлена итоговая функция (оформление заказа), полный комплект спецификаций, релизный PR и обновлённая документация.

## Что нового

Добавлена возможность оформления заказа. Покупатель заполняет адрес доставки, выбирает способ оплаты и получает подтверждение с номером заказа. Реализация прошла полный SDD-цикл в `critical`-режиме: основная спецификация, архитектурные решения, реестр рисков, тесты, ревью, документация.

## Улучшения

- 6 тестов покрывают API checkout и граничные случаи валидации.
- `CartContext` поддерживает очистку корзины после оформления.
- Расширенный README с инструкцией запуска e2e-тестов через MCP.

## Что есть в проекте на этой версии

- Каталог с фильтрами по цене и категориям.
- Корзина с промокодом и расчётом доставки.
- Оформление заказа с валидацией и подтверждением.
- Интеграция с API поставщика, фолбэк на кеш, четыре состояния загрузки.
- Playwright MCP для агентного запуска e2e-тестов.
- Подготовка релиза: CHANGELOG, risk-checklist, заметки к релизу, PR-описание.

## Известные ограничения

- Оплата имитируется (mock API всегда подтверждает заказ).
- Корзина не сохраняется в localStorage между сессиями.
- Изображения товаров — плейсхолдеры.
