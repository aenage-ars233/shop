# Changelog

## [0.1.0] - 2026-11-25

### Added
- Добавлена проверка обязательных полей товара при обработке данных каталога.

### Changed
- Моковые данные теперь используются только при явном включении `VITE_USE_MOCK_DATA=true`.
- При отсутствии поля `in_stock` товар считается отсутствующим на складе.
- Сообщение об ошибке тайм-аута теперь содержит установленную длительность ожидания.

### Fixed
- Некорректный JSON в успешном ответе API теперь распознаётся как ошибка `INVALID_RESPONSE`.

### Removed
