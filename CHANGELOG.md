# Журнал изменений

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.0] - 2026-04-13

Учебный релиз магазина: каталог с фильтрами, корзина с промокодом, оформление заказа, интеграция с API, MCP, тесты и подготовка релиза. Итоговая доработка добавила оформление заказа.

### Добавлено

- Страница оформления заказа с формой адреса и выбором оплаты.
- API-клиент для отправки заказов (`src/api/checkout.js`).
- Подтверждение заказа с номером.
- Полный комплект спецификаций для итоговой функции: `docs/specs/capstone/contract.md`, `architecture.md`, `risk-register.md`.
- Интеграция с API поставщика для каталога: обработка таймаутов, повторы, фолбэк на кеш.
- Четыре состояния загрузки каталога: `loading`, `retrying`, `fallback`, `failed`.
- Скелетон загрузки каталога с анимацией.
- Playwright MCP для агентного запуска e2e-тестов.
- Инвентаризация MCP-инструментов и реестр рисков (`docs/mcp-inventory.md`, `docs/mcp-risk-log.md`).
- Расширенная документация: README, журнал решений, JSDoc для API.
- Чек-лист релизных рисков и заметки к релизу.

### Изменено

- Каталог загружает товары через API вместо статического файла.
- Корзина содержит ссылку на оформление заказа.
- `CartContext` поддерживает очистку корзины после оформления.

### Исправлено

- Корректный расчёт доставки при применении промокода (учитывается сумма после скидки).
- Валидация полей товара в адаптере предотвращает отображение неполных данных.
